ESP32 Earthquake Detector IoT Project

📌 Project Overview
This project is an IoT-based Earthquake Detection and Alert System developed using ESP32 and the MPU6050 accelerometer and gyroscope sensor.

The system monitors motion and acceleration changes to identify unusual vibrations. When the measured movement crosses a predefined threshold, the system activates an alert using an LED and buzzer.

🎯 Objectives
- Monitor movement and vibrations in real time.
- Detect unusual motion using an MPU6050 sensor.
- Generate alerts using LEDs and a buzzer.
- Explore ESP32-based IoT applications.

🛠️ Components Used
- ESP32 Development Board
- MPU6050 Accelerometer and Gyroscope
- Buzzer
- LEDs
- Resistors
- Jumper Wires

⚙️ Working Principle
1. The MPU6050 continuously measures acceleration and angular motion.
2. ESP32 reads and processes the sensor data.
3. The measured values are compared with a predefined threshold.
4. If unusual movement is detected, the alert system is activated.
5. LEDs and buzzer indicate the detected movement condition.
